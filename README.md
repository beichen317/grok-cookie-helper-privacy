# Grok Cookie 助手隐私政策

本仓库用于公开发布 Grok Cookie 助手的隐私政策。站点首页即为完整政策正文。

- 政策网址：https://beichen317.github.io/grok-cookie-helper-privacy/
- 维护者：[beichen317](https://github.com/beichen317)
- 联系：[Issues](https://github.com/beichen317/grok-cookie-helper-privacy/issues)（请勿提交登录 Cookie、密码或其他凭证）

## 发布

在仓库 Settings → Pages 中，选择 Deploy from a branch，分支 main，目录 / (root)。保存并等待部署完成。
使用浏览器无痕窗口确认上述政策网址无需登录即可访问，再填入 Chrome 网上应用店开发者后台的隐私政策网址字段。

## 内容与维护

当前政策描述扩展 v1.0.0 的实际行为。更新扩展的数据处理行为时，请同步维护政策和商店披露。
本仓库仅包含静态政策网页与资源，不包含真实用户数据、Cookie 导出、插件测试样本或登录凭据。
无需安装依赖或编译，无第三方脚本、统计、远程字体或表单。

## 发布前另外待处理的扩展事项

v1.0.0 打开弹窗就读取 Cookie。需在扩展中补充读取前的醒目告知和同意流程，并同步更新政策中的触发方式。
政策页面可访问不代表扩展已通过 Chrome 商店审核。
