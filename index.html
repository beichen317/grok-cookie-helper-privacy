适用范围

本政策说明 Grok Cookie 助手 Chrome 扩展如何处理用户数据。扩展的单一用途是在用户本机查看、复制和导出其本人浏览器中适用于 https://grok.com/ 的 Cookie。

本扩展是独立辅助工具，与 xAI/Grok 无官方关系。它不验证账号订阅状态，不提供订阅开通或付款服务。

读取哪些数据、何时读取

当前 1.0.0 版本在用户打开扩展弹窗或点击“重新读取”时，通过浏览器 Cookie API 读取适用于 https://grok.com/ 的未分区 Cookie。读取范围为当前普通 Chrome 用户配置，不支持无痕窗口。

读取信息包括 Cookie 名称、值、域名、路径、有效期或会话标记，以及 Secure、HttpOnly、SameSite、hostOnly、storeId 等浏览器提供的属性。

这些 Cookie 可能包含 sso、sso-rw 等登录认证信息，以及 Grok 设置的偏好信息、持久标识或其他 Cookie 数据。扩展不解析 Cookie 值中的账号资料，也不会将完整导出内容限制为 sso 一项。

数据用途

读取的数据仅用于显示 Cookie 数量、检查非空 sso 及可选 sso-rw 是否存在、按用户选择显示 Cookie 内容，以及执行复制或 JSON 导出。

Cookie 内容默认隐藏。完整 Cookie 文本保留本次读取的全部 Cookie 名称和值；单独复制 sso 只复制该项值；JSON 复制和下载保留该批 Cookie 的原始属性。检测到 sso 仅表示本地存在该值，不代表登录有效性已经验证。

本机处理与共享

扩展本身不把 Cookie 发送给发布者、远程服务器或其他第三方，不包含广告、统计分析或遥测代码，也不会自动将 Cookie 提交到其他网站。

用户点击复制后，内容会进入系统剪贴板；选择下载后，内容会保存为本地 JSON 文件。用户随后将这些内容粘贴或上传到其他网站，是用户自行发起的后续操作，接收方的数据处理由其自身政策规定。

保存期限与删除

读取的 Cookie 在扩展弹窗内存中临时处理。扩展不使用持久化存储保存 Cookie，弹窗关闭后不在扩展内保留该批数据。

复制后的内容可能保留在系统剪贴板、剪贴板历史或用户启用的系统同步服务中；下载的 JSON 文件保留在浏览器指定的下载位置。这些副本由用户自行清除或删除，关闭或卸载扩展不会自动删除它们。

源 Cookie 仍由浏览器和 Grok 管理。本扩展不修改或删除网站 Cookie。用户可通过浏览器网站数据设置、Grok 的退出登录或账号会话管理功能处理源 Cookie 或相关会话。

权限与用途

cookies
读取目标 URL 适用的 Cookie，包括 HttpOnly 登录 Cookie，供本机查看、复制和导出。
https://grok.com/*
将网站访问权限限制在 Grok。
clipboardWrite
在用户点击复制按钮时，将所选数据写入系统剪贴板。

扩展未申请访问所有网站、浏览历史、后台采集或 Cookie 持久化存储的权限。

用户控制与凭证保护

用户可以选择是否打开扩展、是否显示内容、是否执行复制或导出，也可以通过 Chrome 扩展管理页停用或卸载本扩展。

登录 Cookie 属于认证凭证，持有者可能取得对应账号的访问权限。请妥善保管导出内容，避免在公开页面、截图、评论或共享文件中披露真实凭证。

有限使用声明

本扩展对用户数据的使用遵守 Chrome 网上应用店用户数据政策，包括有限使用要求。数据仅用于上述单一功能，不出售用户数据，不用于广告投放、与功能无关的画像、信用评估或放贷决策。发布者不会通过扩展接收或人工查看用户的 Cookie。

本政策网页与 GitHub 服务

本政策网页不包含 Cookie 读取功能、第三方统计脚本或表单，不会因访问本页面而取得你在 Grok 的登录 Cookie。

本页面由 GitHub Pages 托管。访问页面时，GitHub 可能按其服务规则记录 IP 地址等访问信息；使用 GitHub Issues 联系发布者时，你提交的内容可能公开显示。相关处理见 GitHub 隐私声明。

政策更新与联系

当扩展的数据处理方式发生变化时，发布者将同步更新本政策及商店披露；涉及新的数据用途时，将按适用要求进行告知并取得相应同意。
